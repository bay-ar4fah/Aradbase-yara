# Aradbase-YARA

Aradbase-YARA is a research focused repository containing YARA rules
developed for detecting and studying active malware families.

## Purpose

This project aims to support:

- Malware research  
- Threat hunting  
- Detection engineering  
- DFIR (Digital Forensics & Incident Response)  
- Educational use  

## Scope

Rules in this repository primarily target:

- Infostealers  
- Remote Access Trojans (RATs)  
- Ransomware  
- Loaders / Droppers  
- Generic detection patterns  

Coverage evolves alongside the threat landscape.

## Disclaimer

This repository is intended for **research and defensive purposes only**.

Detection accuracy is not guaranteed. Users should validate rules within
their own environments.

## Contributions

Contributions are welcome. Please ensure rules are:

- Relevant and tested  
- Clearly written  
- Low-noise / low false-positive (best effort)
